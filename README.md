# Side events results site

Static site for GitHub Pages + Firebase (Firestore + Google sign-in). Portuguese by default, EN/PT toggle.

## Using it
- **Events**: the admin adds the custom events to the active competition.
- **Scorers**: the admin adds their Google emails under "Authorised scorers". They sign in, choose the event, type the competitor's ID (the competition number, not the WCA ID), type the times and press Enter on the last one to save.
- Times: `12.34`, `1:02.34`, or digits only (`1234` = 12.34); `DNF`, `DNS`; trailing `+` adds 2 seconds. For count events, whole numbers.
